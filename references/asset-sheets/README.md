Source sprite sheets for Stage 9 stamps: the Arbiter's own sheets on a plain white background, imported through the Asset Library's sheet importer. Each file is named 'sheet [tags].png' (for example 'sheet grassland tree.png'); the words after 'sheet' become the suggested tags when imported. Only approved sheets go here; overwrite a sheet when redoing it.

Stamps are optional decorations the Arbiter places by hand; the Rendered view draws terrain and details in code and never needs these files. The app only uses them through the importer, never loads them directly, and not until Stage 9 is built.
